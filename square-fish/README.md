# square-fish

Demos of the square-tile fish style from daoho.dev (Dao Ho's koi pond).

`index.html` — open it in a browser. Four scenes: Koi, Mosaic, Paper, Deep. Tap to feed.

Written from scratch. Same idea as his, not his code (his repo has no license):
- each fish is a chain of points that follows its head
- every grid cell is tested against the body shape, then drawn as a tile, a letter, or both

Sources:
- https://github.com/Dao-Ho/portfolio — `src/app/components/koi-pond/` (no license, read only)
- https://github.com/stackedlol/ascii-sharks — his inspiration (MIT)
